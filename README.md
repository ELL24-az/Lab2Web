## Tujuan
Praktikum ini bertujuan untuk memahami penggunaan tabel, form,
input HTML, semantic HTML, multimedia, dan validasi form dasar.

## 1. Tabel HTML
Pada praktikum ini dibuat tabel data mahasiswa menggunakan tag table, tr, th, dan td.

## 2. Form HTML
Form digunakan untuk menerima data dari pengguna seperti nama,
email, password, dan tanggal lahir.

## 3. Radio Button dan Checkbox

Radio button digunakan untuk memilih jenis kelamin,
sedangkan checkbox digunakan untuk memilih keahlian.

## 4. Select dan Textarea

Select digunakan untuk memilih program studi dan textarea
digunakan untuk memasukkan alamat.

## 5. Validasi Form

Validasi digunakan untuk memastikan data tertentu wajib diisi
dan memenuhi ketentuan yang telah ditentukan.

## 6. Semantic HTML

Halaman menggunakan semantic HTML seperti header, nav, main,
section, article, aside, dan footer.

## 7. Multimedia

Halaman menampilkan elemen audio dan video menggunakan HTML.

## 8. Proyek Mini Biodata

Proyek mini menggabungkan tabel, form, validasi, dan semantic HTML
dalam satu halaman biodata mahasiswa.

# Jawaban Pertanyaan

### 1. Apa fungsi `<table>`, `<tr>`, `<th>`, dan `<td>`?

`<table>` digunakan untuk membuat tabel.  
`<tr>` digunakan untuk membuat baris pada tabel.  
`<th>` digunakan untuk membuat bagian judul atau header tabel.  
`<td>` digunakan untuk membuat isi atau data pada tabel.

### 2. Apa perbedaan `<th>` dan `<td>`?

`<th>` digunakan sebagai header atau judul kolom pada tabel, sedangkan `<td>` digunakan untuk menampilkan isi atau data pada tabel.

### 3. Apa fungsi `colspan` pada tabel?

`colspan` digunakan untuk menggabungkan beberapa kolom menjadi satu kolom.

### 4. Apa fungsi `<form>` dalam HTML?

`<form>` digunakan untuk membuat formulir yang dapat digunakan untuk menerima data atau input dari pengguna.

### 5. Apa perbedaan radio button dan checkbox?

Radio button digunakan untuk memilih satu pilihan dari beberapa pilihan yang tersedia. Sedangkan checkbox digunakan untuk memilih satu atau beberapa pilihan sekaligus.

### 6. Mengapa `<label>` sebaiknya terhubung dengan id input melalui atribut `for`?

Agar label terhubung dengan input yang sesuai sehingga lebih mudah digunakan dan membantu pengguna mengetahui input yang harus diisi.

### 7. Apa perbedaan `<textarea>` dengan input type text?

`<input type="text">` digunakan untuk memasukkan teks dalam satu baris, sedangkan `<textarea>` digunakan untuk memasukkan teks yang lebih panjang dan dapat terdiri dari beberapa baris.

### 8. Apa fungsi semantic HTML seperti `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`?

Semantic HTML digunakan untuk memberikan struktur yang jelas pada halaman web.

- `<header>` digunakan untuk bagian kepala halaman.
- `<nav>` digunakan untuk navigasi.
- `<main>` digunakan untuk konten utama.
- `<section>` digunakan untuk mengelompokkan bagian tertentu.
- `<article>` digunakan untuk konten atau artikel yang berdiri sendiri.
- `<aside>` digunakan untuk konten tambahan atau sampingan.
- `<footer>` digunakan untuk bagian bawah halaman.

### 9. Apa fungsi `required`, `min`, `max`, dan `minlength`?

`required` digunakan agar input wajib diisi.  
`min` digunakan untuk menentukan nilai minimum.  
`max` digunakan untuk menentukan nilai maksimum.  
`minlength` digunakan untuk menentukan jumlah karakter minimum yang harus dimasukkan.

### 10. Apa perbedaan elemen `<audio>` dan `<video>`?

`<audio>` digunakan untuk menampilkan atau memutar file suara, sedangkan `<video>` digunakan untuk menampilkan atau memutar file video.
